# Кухни на заказ — лэндинг-шаблон

Демо-лендинг для ниши «кухни на заказ» (Татарстан). Собран так, чтобы под нового клиента
пересобираться за ~20 минут правкой одного файла.

**Идея:** не продавать «красивую кухню», а показать **понятную кухню с ценой, сроком
и составом ещё до звонка**. Визуальный язык — не каталог интерьеров, а лист замера,
карта раскроя и спецификация: сетка, штампы, выноски, номера позиций.

Полное ТЗ — в [description.md](description.md).

---

## Стек

| Слой | Решение |
| --- | --- |
| Фреймворк | Astro 5 (статическая генерация) |
| Стили | Tailwind v4 + CSS-токены в `src/styles/global.css` |
| Типы | TypeScript strict |
| Анимации | GSAP + ScrollTrigger, Lenis |
| Интерактив | ванильный TS в `<script>` Astro (без React — экономим JS) |
| Изображения | webp-фото + SVG-техкарта; без фотостоков и чужих брендов |
| Лиды | `wa.me` без бэкенда |

JS первой загрузки: ~62 KB gz (gsap + ScrollTrigger + lenis + логика). Бюджет — 180 KB.

Дев-сервер: `http://localhost:4321/kitchen-template/` (сайт живёт в подпапке из-за GitHub Pages).

**Отладочный флаг:** `?nomotion` — страница ведёт себя как при `prefers-reduced-motion`:
без Lenis, без пина, всё видно сразу. Удобно для проверки вёрстки и доступности.

## Пересборка под клиента

### 1. Единственный обязательный файл

`src/config/client.ts` — **весь клиентский слой**: город, название, реквизиты, телефон,
WhatsApp, адрес, карта, график, цены, коэффициенты, гарантия, материалы, категории,
портфолио, FAQ, отзывы, дисклеймеры.

Правило шаблона: **ни одного города, телефона, цены, адреса, срока или гарантии вне
`clientConfig`.** В компонентах — только подстановки.

Ключевые поля:

| Поле | Что меняет |
| --- | --- |
| `demoMode` | показывает в подвале плашку «демо-данные». У реального клиента — `false` |
| `heroTitleVariant` | 1, 2 или 3 — какой из трёх H1 показывать |
| `pricing.basePerMeter` | ставка за погонный метр по типу фасада |
| `pricing.shapeCoeff` | наценка за форму (прямая → остров) |
| `pricing.hardwarePack` | пакеты фурнитуры |
| `quiz.*` | коэффициенты и сроки для квиза |
| `tiers` | переключатель эконом / стандарт / премиум в блоке цен |
| `metrika.counterId` | ID счётчика Яндекс.Метрики; `null` — цели молча не отправляются |

### 2. Домен

`astro.config.mjs`:

```js
site: 'https://domain.ru',
base: '/',
```

Для GitHub Pages остаётся `base: '/kitchen-template'`.

### 3. Фотографии

В `public/assets/` лежат 21 демо-изображение (webp, ~980 КБ на всю страницу).
Все сгенерированы одной серией, поэтому свет и палитра у них общие; брендов,
логотипов и читаемого текста в кадрах нет.

| Файл | Где используется |
| --- | --- |
| `hero-kitchen.webp` | первый экран, под техкартой |
| `work-1…6.webp` | лента работ |
| `mat-*.webp` | макро образцов материалов |
| `cat-*.webp` | изометрия форматов, **PNG с альфой** → webp |
| `quiz-sheet.webp` | боковая панель подбора |
| `calc-measure.webp` | калькулятор |

Чтобы подставить фото клиента — заменить файлы с теми же именами либо поправить
поля `image` в `src/config/client.ts` (`portfolio[].image`, `materials[].image`,
`categories[].image`). **Если поля `image` нет — рисуется векторный запасной
вариант** (`KitchenRender`, `ShapePlan`), вёрстка не разъезжается.

Требования к фото: hero — до 280 КБ, карточки — 800–1200 px по ширине,
всё ниже первого экрана с `loading="lazy"`.

Шот-лист для съёмки — раздел 6 в `description.md`.

## Юридический слой

Заложено по требованиям 152-ФЗ, ЗоЗПП и ТР ТС 025/2012:

- политика конфиденциальности и согласие на обработку ПДн — отдельными страницами;
- подпись под кнопками о согласии (без предустановленных галочек — формы на сервер нет,
  человек сам пишет данные в мессенджере);
- реквизиты юрлица/ИП в подвале;
- строка о том, что цена уточняется в договоре после замера;
- строка о неоферте;
- упоминание соответствия ТР ТС 025/2012.

Тексты документов — шаблонные. Перед публикацией у реального клиента их проверяет юрист.

## Доступность и motion

- вся интерактивность работает с клавиатуры, кнопки ≥ 44 px;
- фокус видимый (латунный контур), контраст не ниже AA;
- при `prefers-reduced-motion: reduce` не грузятся ни GSAP, ни Lenis;
- пин первого экрана — только на десктопе с мышью (`pointer: fine`): на тач-устройствах
  связка `pin + 100svh` ломается первой;
- нет автокаруселей, параллакса, видеофонов и 3D-поворотов.

## Деплой

Пуш в `main` → GitHub Actions собирает и публикует на GitHub Pages
(`.github/workflows/deploy.yml`).

Первый деплой требует, чтобы в **Settings → Pages → Build and deployment → Source**
стоял вариант **GitHub Actions** (workflow пытается включить это сам через
`configure-pages` с `enablement: true`).
